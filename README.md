# WoodCell-QWA: Angiosperm Xylogenesis & Quantitative Wood Anatomy

Aplicación web interactiva para la segmentación de fases de crecimiento del xilema y floema en especies leñosas angiospermas.

## Código Cromático por Fenofase (Marchand et al., 2026):
- **Magenta (`#FF00FF`):** Zona Cambial (CZ)
- **Cian (`#00FFFF`):** Fase I - Expansión Celular / Post-cambial (E)
- **Naranja (`#FFC800`):** Fase II - Depósito de Pared Secundaria (W)
- **Rojo (`#FF0000`):** Fase III - Lignificación (L)
- **Verde (`#00FF00`):** Fase IV - Célula Madura / Muerte Celular Programada (M)
