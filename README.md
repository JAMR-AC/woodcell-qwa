# WoodCell-QWA: Angiosperm Xylogenesis & Quantitative Wood Anatomy

Aplicación web interactiva para la segmentación de fases de crecimiento del xilema y floema en especies leñosas angiospermas teñidas con Azul de Astra y Safranina.

## Características Clave:
1. **Protección de Archivos Originales:** Las imágenes cargadas no se modifican ni sobrescriben jamás. Toda exportación o trazo de medición genera un archivo independiente con nuevo nombre.
2. **Medición Manual y Automática:** Permite tanto la segmentación y cálculo biométrico por lotes como la medición directa punto a punto sobre la microfotografía.
3. **Criterios Científicos:** Basado en el marco metodológico de Marchand et al. (2026) (*Quantitative Plant Biology*).
